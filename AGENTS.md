# qyl-api-schema

TypeSpec source for OpenAPI, JSON Schema, TypeScript (@ancplua/qyl-api-schema) and C# (Qyl.Api.Contracts). Layout and generation: CONTRIBUTING.md. Releases and consumer order: SKILL.md. This repository owns API models, validators and the contract handshake; SemanticConventions owns telemetry definitions. Contracts have no telemetry runtime dependency.
